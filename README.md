# Мақсат туралы: Git тәжірибесі

Менің атым Мақсат.

Мен осы жобада файл өзгерістерін сақтауды жаттығамын.

## GitHub және git pull

Бұл README GitHub репозиторийінде жаңартылды.
Қашықтағы өзгерісті компьютердегі жобаға алу үшін `git pull` командасы қолданылды.
